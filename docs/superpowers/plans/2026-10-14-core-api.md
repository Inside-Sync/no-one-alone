# core-api Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build core-api, the only writer of incident state, so the stroke, fall and false-alarm scenarios run end to end on Cloud Run as `docs/contract.md` describes.

**Architecture:** Spring Boot service with one Firestore-backed incident document per alert. A synchronous pipeline (`IncidentFlow`) runs verify, check-in and triage against respond-agent; `Escalation` and `Actions` own the Health Circle state machine with Cloud Tasks timers; `Handoff` picks a hospital and calls respond-agent's `/handoff`. Controllers answer fast and hand slow work to one executor.

**Tech Stack:** Java 17, Spring Boot 3.3.4 (web, RestClient), Google Cloud libraries BOM 26.47.0 (Firestore, Pub/Sub, Cloud Tasks, Storage), firebase-admin 9.3.0, Testcontainers Firestore emulator, JUnit 5, Mockito.

**Spec:** `docs/contract.md` (v1.2; Task 1 bumps it to v1.3).

## Global Constraints

- Timestamps are ISO-8601 UTC strings with `Z`, second precision, in story time (`realNow + demo.clockOffsetMs`).
- Absent optional fields are omitted, never `null`, except `ownerId`, which is `null` until someone accepts.
- Enums are UPPER_SNAKE strings.
- Only core-api writes `incidents` and `demo/current`. Every incident write goes through `IncidentStore.mutate` (transaction, `version + 1`, `updatedAt`).
- Public routes live under `/api` (Firebase Hosting rewrite). Internal routes `/alerts` and `/tasks/escalation-timeout` stay at the root.
- Public routes answer within 60 s; slow work runs on the shared executor after responding.
- Errors use `{ "error": { "code": "...", "message": "..." } }` with codes `INVALID_REQUEST` 400, `UNAUTHENTICATED` 401, `NOT_FOUND` 404, `ALREADY_OWNED` 409, `INVALID_STATE` 409, `AGENT_FAILED` 502.
- Task names: `{incidentId}-{memberId}-{attempt}`. Deleting a task is best effort.
- Region `asia-southeast1`. No keys in the repo.
- Escalation order is decided by code, never by the LLM.
- Safety instructions to the person come only from respond-agent's script library; core-api never writes its own.

## Review Focus

1. Two NEARBY members tap Accept at the same moment: exactly one becomes owner, the other gets `409 ALREADY_OWNED` naming the owner. Test in Task 10.
2. Pub/Sub delivers the same alert twice while the first is still processing: one incident, respond-agent `/verify` called once. Test in Task 5 and Task 7.
3. The escalation timer fires after the member already accepted (task deletion failed): nothing changes, no new task. Test in Task 10 (`timeoutAfterAcceptChangesNothing`, `lateAcceptStopsTheNextTimer`).
4. respond-agent is down or times out mid check-in: the incident still reaches a level with `fallback: true`, an `AGENT_FALLBACK` timeline entry, and `checkIn.busy` back to `false`. Test in Task 8 (`agentDownMidCheckInStillReachesALevel`, `unexpectedFailureClearsBusy`).
5. The person screen double-submits an answer: the second post gets `409 INVALID_STATE` and no duplicate turn is written. Test in Task 8.

## Working rules for implementers

- Branch `feat/core-api` from `dev`, in a worktree. Commit after each task locally. Pushing needs Dũng's approval.
- Every test step names a **red edit**: a one-line production change that must make that test fail. Apply it, run the test, paste the failing output into `.superpowers/sdd/2026-10-14-core-api/checks.md`, revert it, run again green.
- Docker Desktop must be running: Firestore tests start the emulator with Testcontainers. The first pull of the emulator image takes a few minutes.
- Run tests with `mvn -q -B test` from `core-api/`. Use a clean build (`mvn -q -B clean test`) before reporting a task green.
- Comments: at most one short line, only where the code cannot say it.
- M1 runs with AUTH off, so `/alerts` and `/tasks/*` are open on the run.app URL until M2. Do not share that URL; note it in checks.md.

```java
package com.noonealone.coreapi.config;

import java.net.http.HttpClient;
import java.time.Clock;
import java.time.Duration;
import java.util.concurrent.Executor;
import java.util.concurrent.ExecutorService;
import java.util.concurrent.Executors;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.web.client.RestClientCustomizer;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;
import org.springframework.http.client.JdkClientHttpRequestFactory;

import com.google.cloud.NoCredentials;
import com.google.cloud.firestore.Firestore;
import com.google.cloud.firestore.FirestoreOptions;

@Configuration
public class GcpConfig {

    private static final Logger log = LoggerFactory.getLogger(GcpConfig.class);

    @Bean
    Firestore firestore(NoaProperties props) {
        FirestoreOptions.Builder builder = FirestoreOptions.newBuilder().setProjectId(props.projectId());
        String host = props.firestoreEmulatorHost();
        if (host != null && !host.isBlank()) {
            builder.setEmulatorHost(host).setCredentials(NoCredentials.getInstance());
        }
        return builder.build().getService();
    }

    @Bean
    Clock clock() {
        return Clock.systemUTC();
    }

    @Bean
    Executor workExecutor() {
        ExecutorService pool = Executors.newFixedThreadPool(8);
        return task -> pool.execute(() -> {
            try {
                task.run();
            } catch (RuntimeException e) {
                log.error("Background work failed", e);
            }
        });
    }

    @Bean
    RestClientCustomizer timeouts() {
        HttpClient client = HttpClient.newBuilder().connectTimeout(Duration.ofSeconds(5)).build();
        JdkClientHttpRequestFactory factory = new JdkClientHttpRequestFactory(client);
        factory.setReadTimeout(Duration.ofSeconds(60));
        return builder -> builder.requestFactory(factory);
    }
}
```

```java
package com.noonealone.coreapi.web;

import org.springframework.http.HttpStatus;

public class ApiException extends RuntimeException {

    private final HttpStatus status;
    private final String code;

    public ApiException(HttpStatus status, String code, String message) {
        super(message);
        this.status = status;
        this.code = code;
    }

    public static ApiException notFound(String message) {
        return new ApiException(HttpStatus.NOT_FOUND, "NOT_FOUND", message);
    }

    public static ApiException conflict(String code, String message) {
        return new ApiException(HttpStatus.CONFLICT, code, message);
    }

    public static ApiException invalidState(String message) {
        return conflict("INVALID_STATE", message);
    }

    public static ApiException badRequest(String message) {
        return new ApiException(HttpStatus.BAD_REQUEST, "INVALID_REQUEST", message);
    }

    public HttpStatus status() {
        return status;
    }

    public String code() {
        return code;
    }
}
```

`…/web/ApiErrors.java`:

```java
package com.noonealone.coreapi.web;

import java.util.Map;

import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.http.converter.HttpMessageNotReadableException;
import org.springframework.web.bind.annotation.ExceptionHandler;
import org.springframework.web.bind.annotation.RestControllerAdvice;
import org.springframework.web.multipart.support.MissingServletRequestPartException;

@RestControllerAdvice
public class ApiErrors {

    @ExceptionHandler(ApiException.class)
    ResponseEntity<Map<String, Object>> handle(ApiException e) {
        return body(e.status(), e.code(), e.getMessage());
    }

    @ExceptionHandler({HttpMessageNotReadableException.class, MissingServletRequestPartException.class})
    ResponseEntity<Map<String, Object>> unreadable(Exception e) {
        return body(HttpStatus.BAD_REQUEST, "INVALID_REQUEST", "Request body is missing or malformed");
    }

    private static ResponseEntity<Map<String, Object>> body(HttpStatus status, String code, String message) {
        return ResponseEntity.status(status).body(Map.of("error", Map.of("code", code, "message", message)));
    }
}
```

```java
package com.noonealone.coreapi.store;

import java.time.Clock;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.Optional;
import java.util.concurrent.ExecutionException;

import org.springframework.stereotype.Component;

import com.google.api.core.ApiFuture;
import com.google.cloud.firestore.DocumentReference;
import com.google.cloud.firestore.DocumentSnapshot;
import com.google.cloud.firestore.Firestore;
import com.google.cloud.firestore.WriteBatch;
import com.noonealone.coreapi.data.SeedData;
import com.noonealone.coreapi.model.DemoCurrent;
import com.noonealone.coreapi.model.Docs;
import com.noonealone.coreapi.model.Hospital;
import com.noonealone.coreapi.model.Incident;
import com.noonealone.coreapi.model.Person;
import com.noonealone.coreapi.model.StoryClock;
import com.noonealone.coreapi.web.ApiException;

@Component
public class IncidentStore {

    @FunctionalInterface
    public interface Change {
        boolean apply(Incident incident, String now);
    }

    public record Mutation(Incident incident, boolean changed) {}

    private final Firestore db;
    private final Clock clock;

    public IncidentStore(Firestore db, Clock clock) {
        this.db = db;
        this.clock = clock;
    }

    public boolean createIfAbsent(Incident incident) {
        DocumentReference ref = incidentRef(incident.id);
        return call(db.runTransaction(tx -> {
            if (tx.get(ref).get().exists()) {
                return false;
            }
            tx.set(ref, Docs.toMap(incident));
            return true;
        }));
    }

    public Optional<Incident> find(String id) {
        DocumentSnapshot snap = call(incidentRef(id).get());
        return snap.exists() ? Optional.of(read(snap)) : Optional.empty();
    }

    public Incident get(String id) {
        return find(id).orElseThrow(() -> ApiException.notFound("Incident " + id + " not found"));
    }

    public Mutation mutate(String id, Change change) {
        DocumentReference ref = incidentRef(id);
        return call(db.runTransaction(tx -> {
            DocumentSnapshot snap = tx.get(ref).get();
            if (!snap.exists()) {
                throw ApiException.notFound("Incident " + id + " not found");
            }
            Incident incident = read(snap);
            String now = StoryClock.now(incident.demo.clockOffsetMs, clock);
            if (!change.apply(incident, now)) {
                return new Mutation(incident, false);
            }
            incident.version++;
            incident.updatedAt = now;
            tx.set(ref, Docs.toMap(incident));
            return new Mutation(incident, true);
        }));
    }

    public void delete(String id) {
        call(incidentRef(id).delete());
    }

    public Optional<DemoCurrent> current() {
        DocumentSnapshot snap = call(currentRef().get());
        return snap.exists() ? Optional.of(Docs.fromMap(snap.getData(), DemoCurrent.class)) : Optional.empty();
    }

    public void setCurrent(DemoCurrent current) {
        call(currentRef().set(Docs.toMap(current)));
    }

    public void clearCurrent() {
        call(currentRef().delete());
    }

    public Person person(String id) {
        DocumentSnapshot snap = call(db.collection("people").document(id).get());
        if (!snap.exists()) {
            throw ApiException.notFound("Person " + id + " not found");
        }
        Person p = Docs.fromMap(snap.getData(), Person.class);
        p.id = id;
        return p;
    }

    public Map<String, Person> people() {
        Map<String, Person> result = new HashMap<>();
        for (DocumentSnapshot snap : call(db.collection("people").get()).getDocuments()) {
            Person p = Docs.fromMap(snap.getData(), Person.class);
            p.id = snap.getId();
            result.put(p.id, p);
        }
        return result;
    }

    public List<Hospital> hospitals() {
        return call(db.collection("hospitals").get()).getDocuments().stream().map(snap -> {
            Hospital h = Docs.fromMap(snap.getData(), Hospital.class);
            h.id = snap.getId();
            return h;
        }).toList();
    }

    public void seed(SeedData seed) {
        WriteBatch batch = db.batch();
        seed.people().forEach((id, p) -> batch.set(db.collection("people").document(id), Docs.toMap(p)));
        seed.hospitals().forEach((id, h) -> batch.set(db.collection("hospitals").document(id), Docs.toMap(h)));
        call(batch.commit());
    }

    private DocumentReference incidentRef(String id) {
        return db.collection("incidents").document(id);
    }

    private DocumentReference currentRef() {
        return db.collection("demo").document("current");
    }

    private static Incident read(DocumentSnapshot snap) {
        Incident incident = Docs.fromMap(snap.getData(), Incident.class);
        incident.id = snap.getId();
        return incident;
    }

    private static <T> T call(ApiFuture<T> future) {
        try {
            return future.get();
        } catch (InterruptedException e) {
            Thread.currentThread().interrupt();
```

```java
import com.google.auth.oauth2.GoogleCredentials;
import com.google.auth.oauth2.IdTokenCredentials;
import com.google.auth.oauth2.IdTokenProvider;

class IdTokenInterceptor implements ClientHttpRequestInterceptor {

    private final IdTokenCredentials credentials;

    IdTokenInterceptor(String audience) {
        try {
            GoogleCredentials adc = GoogleCredentials.getApplicationDefault();
            credentials = IdTokenCredentials.newBuilder()
                    .setIdTokenProvider((IdTokenProvider) adc)
                    .setTargetAudience(audience)
                    .build();
        } catch (IOException e) {
            throw new IllegalStateException("No application default credentials for service-to-service calls", e);
        }
    }

    @Override
    public ClientHttpResponse intercept(HttpRequest request, byte[] body, ClientHttpRequestExecution execution)
            throws IOException {
        credentials.refreshIfExpired();
        request.getHeaders().setBearerAuth(credentials.getIdToken().getTokenValue());
        return execution.execute(request, body);
    }
}
```

```java
@Component
public class AudioStore {

    private static final Logger log = LoggerFactory.getLogger(AudioStore.class);

    private final boolean enabled;
    private final String bucket;
    private final Storage storage;

    public AudioStore(NoaProperties props) {
        this.enabled = props.audio().enabled();
        this.bucket = props.audio().bucket();
        this.storage = enabled ? StorageOptions.getDefaultInstance().getService() : null;
    }

    public String save(String incidentId, String fileName, byte[] data, String contentType) {
        if (!enabled || data == null) {
            return null;
        }
        String path = "audio/" + incidentId + "/" + fileName;
        try {
            storage.create(BlobInfo.newBuilder(bucket, path).setContentType(contentType).build(), data);
            return path;
        } catch (RuntimeException e) {
            log.warn("Could not store {}", path, e);
            return null;
        }
    }

    public void deleteIncident(String incidentId) {
        if (!enabled) {
            return;
        }
        try {
            for (Blob blob : storage.list(bucket, Storage.BlobListOption.prefix("audio/" + incidentId + "/")).iterateAll()) {
                blob.delete();
            }
        } catch (RuntimeException e) {
            log.warn("Could not delete audio for {}", incidentId, e);
        }
    }
}
```

```java
public class IncidentFlow {

    static final int MAX_AGENT_TURNS = 4;

    private final IncidentStore store;
    private final RespondAgentClient agent;
    private final Scenarios scenarios;
    private final AudioStore audio;
    private final Clock clock;

    public IncidentFlow(IncidentStore store, RespondAgentClient agent, Scenarios scenarios, AudioStore audio, Clock clock) {
        this.store = store;
        this.agent = agent;
        this.scenarios = scenarios;
        this.audio = audio;
        this.clock = clock;
    }

    public boolean create(AlertMessage msg) {
        String now = StoryClock.now(msg.demo().clockOffsetMs, clock);
        Incident inc = new Incident();
        inc.id = msg.alertId();
        inc.personId = msg.personId();
        inc.scenario = msg.scenario();
        inc.status = Status.VERIFYING;
        inc.version = 1;
        inc.createdAt = now;
        inc.updatedAt = now;
        inc.alert = new Alert();
        inc.alert.kind = msg.kind();
        inc.alert.at = now;
        inc.alert.hr = msg.hr();
        inc.alert.movementMin = msg.movementMin();
        inc.demo = msg.demo();
        inc.log(now, "SYSTEM", "ALERT", "HR " + msg.hr() + ", no movement " + msg.movementMin() + " min");
        return store.createIfAbsent(inc);
    }

    public void process(String incidentId) {
        Incident inc = store.get(incidentId);
        Person person = store.person(inc.personId);
        VerifyResult v;
        boolean agentDown = false;
        try {
            v = agent.verify(verifyBody(inc, person));
        } catch (AgentException e) {
            v = new VerifyResult(true, "respond-agent unavailable, alert treated as real", null, true);
            agentDown = true;
        }
        VerifyResult result = v;
        boolean down = agentDown;
        store.mutate(incidentId, (x, now) -> {
            if (x.status != Status.VERIFYING) {
                return false;
            }
            x.verify = new Verify();
            x.verify.isReal = result.isReal();
            x.verify.reason = result.reason();
            x.verify.fallback = result.fallback();
            x.lastKnownWellAt = result.lastKnownWellAt();
            if (down) {
                x.log(now, "AGENT", "AGENT_FALLBACK", "Verify used fallback");
            }
            if (result.isReal()) {
                x.status = Status.CHECKING_IN;
                x.log(now, "AGENT", "VERIFIED", result.reason());
            } else {
                x.status = Status.CLOSED;
                x.log(now, "AGENT", "FALSE_ALARM", result.reason());
            }
            return true;
        });
        if (result.isReal()) {
            askNext(incidentId, null);
        }

        Person person = store.person(inc.personId);
```

```java
import com.noonealone.coreapi.config.NoaProperties;
import com.noonealone.coreapi.flow.AlertIntake;
import com.noonealone.coreapi.flow.AlertMessage;
import com.noonealone.coreapi.model.Docs;

@Component
public class AlertPublisher {

    private final Publisher publisher;
    private final AlertIntake intake;
    private final Executor executor;

    public AlertPublisher(NoaProperties props, AlertIntake intake, Executor executor) {
        this.intake = intake;
        this.executor = executor;
        try {
            this.publisher = props.pubsub().enabled()
                    ? Publisher.newBuilder(TopicName.of(props.projectId(), props.pubsub().topic())).build()
                    : null;
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }

    public void publish(AlertMessage msg) {
        if (publisher == null) {
            executor.execute(() -> intake.receive(msg));
            return;
        }
        try {
            byte[] json = Docs.mapper().writeValueAsBytes(msg);
            publisher.publish(PubsubMessage.newBuilder().setData(ByteString.copyFrom(json)).build())
                    .get(10, TimeUnit.SECONDS);
        } catch (Exception e) {
            throw new IllegalStateException("Could not publish alert " + msg.alertId(), e);
        }
    }
}
```

```java
@Component
public class EscalationTimers {

    private static final Logger log = LoggerFactory.getLogger(EscalationTimers.class);

    private final NoaProperties.Tasks config;
    private final QueueName queue;
    private final CloudTasksClient client;

    public EscalationTimers(NoaProperties props) {
        this.config = props.tasks();
        this.queue = QueueName.of(props.projectId(), props.region(), config.queue());
        try {
            this.client = config.enabled() ? CloudTasksClient.create() : null;
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
    }

    public String taskName(String incidentId, String memberId, int attempt) {
        return queue + "/tasks/" + incidentId + "-" + memberId + "-" + attempt;
    }

    public String schedule(String incidentId, String memberId, int attempt, int delaySeconds) {
        String name = taskName(incidentId, memberId, attempt);
        if (!config.enabled()) {
            log.info("Cloud Tasks disabled; not scheduling {}", name);
            return name;
        }
        Instant at = Instant.now().plusSeconds(delaySeconds);
        Task task = Task.newBuilder()
                .setName(name)
                .setScheduleTime(Timestamp.newBuilder().setSeconds(at.getEpochSecond()))
                .setHttpRequest(HttpRequest.newBuilder()
                        .setUrl(config.targetUrl() + "/tasks/escalation-timeout")
                        .setHttpMethod(HttpMethod.POST)
                        .putHeaders("Content-Type", "application/json")
                        .setBody(ByteString.copyFrom(json(Map.of("incidentId", incidentId, "memberId", memberId, "attempt", attempt))))
                        .setOidcToken(OidcToken.newBuilder()
                                .setServiceAccountEmail(config.invokerEmail())
                                .setAudience(config.targetUrl())))
                .build();
        try {
            client.createTask(queue, task);
        } catch (AlreadyExistsException e) {
            log.info("Task {} already exists", name);
        }
        return name;
    }

    public void deleteQuietly(String name) {
        if (!config.enabled() || name == null) {
            return;
        }
        try {
            client.deleteTask(name);
        } catch (RuntimeException e) {
            log.debug("Task {} not deleted: {}", name, e.getMessage());
        }
    }

    private static byte[] json(Object value) {
        try {
            return Docs.mapper().writeValueAsBytes(value);
        } catch (JsonProcessingException e) {
            throw new IllegalStateException(e);
        }
    }
}
```

```java
    public void acceptCheckIn(String incidentId, CheckInInput input) {
        int kinds = (input.audio() != null ? 1 : 0) + (input.yesNo() != null ? 1 : 0) + (input.noReply() ? 1 : 0);
        if (kinds != 1) {
            throw ApiException.badRequest("Send exactly one of audio, yesNo or noReply");
        }
        if (input.yesNo() != null && !List.of("YES", "NO").contains(input.yesNo())) {
            throw ApiException.badRequest("yesNo must be YES or NO");
        }
        store.mutate(incidentId, (x, now) -> {
            if (x.status != Status.CHECKING_IN || x.checkIn.done || x.checkIn.busy) {
                throw ApiException.invalidState("Check-in is not waiting for an answer");
            }
            x.checkIn.busy = true;
            x.checkIn.pending = null;
            if (input.noReply()) {
                x.checkIn.noReplyCount++;
                x.log(now, "PERSON", "NO_REPLY", "No reply");
            }
            return true;
        });
    }

    public void processCheckIn(String incidentId, CheckInInput input) {
        try {
            Incident inc = store.get(incidentId);
            if (input.noReply() && inc.checkIn.noReplyCount >= 2) {
                store.mutate(incidentId, (x, now) -> {
                    x.checkIn.done = true;
                    x.checkIn.busy = false;
                    return true;
                });
                finishCheckIn(incidentId);
                return;
            }
            askNext(incidentId, input);
        } catch (RuntimeException e) {
            store.mutate(incidentId, (x, now) -> {
                if (!x.checkIn.busy) {
                    return false;
                }
                x.checkIn.busy = false;
                return true;
            });
            throw e;
        }
    }

    void finishCheckIn(String incidentId) {
        Incident inc = store.get(incidentId);
        TriageResult r;
        try {
            r = agent.triage(triageBody(inc));
        } catch (AgentException e) {
            r = new TriageResult(fallbackLevel(inc), List.of("respond-agent unavailable"), true);
        }
        TriageResult result = r;
        store.mutate(incidentId, (x, now) -> {
            if (x.level != null) {
                return false;
            }
            x.level = result.level();
            x.triage = new Triage();
            x.triage.reasons = result.reasons();
            x.triage.fallback = result.fallback();
            if (result.fallback()) {
                x.log(now, "AGENT", "AGENT_FALLBACK", "Triage used fallback");
            }
            x.log(now, "AGENT", "TRIAGED", "Level " + result.level() + ": " + String.join(", ", result.reasons()));
            if (result.level() == Level.OK || result.level() == Level.MONITOR) {
                x.status = Status.CLOSED;
                x.log(now, "SYSTEM", "CLOSED", "Closed after check-in");
            }
            return true;
        });
    }

    static Level fallbackLevel(Incident inc) {
        return inc.hasSlurredTurn() ? Level.EMERGENCY : Level.COME_NOW;
    }

    private Map<String, Object> triageBody(Incident inc) {
        List<Map<String, Object>> turns = new ArrayList<>();
        for (Turn t : inc.checkIn.turns) {
            Map<String, Object> m = new HashMap<>();
            m.put("by", t.by);
            m.put("text", t.text);
            if (t.assessment != null) {
                m.put("assessment", t.assessment);
            }
            turns.add(m);
        }
        Map<String, Object> alert = new HashMap<>();
        alert.put("kind", inc.alert.kind);
        alert.put("hr", inc.alert.hr);
        return Map.of("alert", alert, "verify", Map.of("isReal", true), "turns", turns,
                "noReplyCount", inc.checkIn.noReplyCount);
    }
```

```java
import org.springframework.web.client.RestClient;

import com.noonealone.coreapi.config.NoaProperties;
import com.noonealone.coreapi.model.LatLng;

@Component
public class RoutesClient {

    private final RestClient http;
    private final String apiKey;

    public RoutesClient(NoaProperties props, RestClient.Builder builder) {
        this.apiKey = props.maps().apiKey();
        this.http = builder.baseUrl("https://routes.googleapis.com").build();
    }

    public Optional<Integer> etaMinutes(LatLng from, LatLng to) {
        if (apiKey == null || apiKey.isBlank() || from == null || to == null) {
            return Optional.empty();
        }
        Map<String, Object> body = Map.of("origin", waypoint(from), "destination", waypoint(to), "travelMode", "DRIVE");
        try {
            Map<?, ?> res = http.post().uri("/directions/v2:computeRoutes")
                    .header("X-Goog-Api-Key", apiKey)
                    .header("X-Goog-FieldMask", "routes.duration")
                    .contentType(MediaType.APPLICATION_JSON)
                    .body(body).retrieve().body(Map.class);
            List<?> routes = res == null ? null : (List<?>) res.get("routes");
            if (routes == null || routes.isEmpty()) {
                return Optional.empty();
            }
            String duration = (String) ((Map<?, ?>) routes.get(0)).get("duration");
            long seconds = Long.parseLong(duration.replace("s", ""));
            return Optional.of((int) Math.ceil(seconds / 60.0));
        } catch (RuntimeException e) {
            return Optional.empty();
        }
    }

    private static Map<String, Object> waypoint(LatLng p) {
        return Map.of("location", Map.of("latLng", Map.of("latitude", p.lat, "longitude", p.lng)));
    }
}
```

```java
public class Actions {

    private final IncidentStore store;
    private final EscalationTimers tasks;

    public Actions(IncidentStore store, EscalationTimers tasks) {
        this.store = store;
        this.tasks = tasks;
    }

    public long apply(String incidentId, String memberId, String action) {
        return switch (action) {
            case "ACCEPT" -> accept(incidentId, memberId);
            case "DECLINE" -> decline(incidentId, memberId);
            case "ARRIVED" -> arrived(incidentId, memberId);
            case "CALLED_115" -> called115(incidentId, memberId);
            case "CLOSE" -> close(incidentId, memberId);
            default -> throw ApiException.badRequest("Unknown action " + action);
        };
    }

    public void timeout(String incidentId, String memberId, int attempt) {
        Optional<Incident> found = store.find(incidentId);
        if (found.isEmpty() || !timedOut(found.get(), memberId)) {
            return;
        }
        Incident inc = found.get();
        Map<String, Person> people = store.people();
        Optional<Assignment> next = nextAfter(inc, memberId);
        String nextTask = next.map(a -> tasks.schedule(incidentId, a.memberId, 1, inc.demo.timerSeconds)).orElse(null);
        store.mutate(incidentId, (x, now) -> {
            if (!timedOut(x, memberId)) {
                return false;
            }
            Assignment a = x.assignment(memberId).orElseThrow();
            a.state = AssignmentState.EXPIRED;
            x.log(now, "SYSTEM", "EXPIRED", EscalationRules.name(people, memberId) + " did not answer");
            notifyNextOrGiveUp(x, now, nextTask, people);
            return true;
        });
    }

    private long accept(String incidentId, String memberId) {
        Map<String, Person> people = store.people();
        IncidentStore.Mutation m = store.mutate(incidentId, (x, now) -> {
            requireStatus(x, Status.ESCALATING);
            if (memberId.equals(x.ownerId)) {
                return false;
            }
            if (x.ownerId != null) {
                throw ApiException.conflict("ALREADY_OWNED",
                        EscalationRules.name(people, x.ownerId) + " is already on the way");
            }
            Assignment a = x.assignment(memberId)
                    .filter(as -> as.role == Role.NEARBY)
                    .filter(as -> as.state == AssignmentState.NOTIFIED || as.state == AssignmentState.EXPIRED)
                    .orElseThrow(() -> ApiException.invalidState(memberId + " cannot accept now"));
            a.state = AssignmentState.ACCEPTED;
            a.respondedAt = now;
            x.ownerId = memberId;
            x.log(now, memberId, "ACCEPTED", EscalationRules.name(people, memberId) + " is on the way");
            return true;
        });
        if (m.changed()) {
            tasks.deleteQuietly(m.incident().escalationTaskName);
        }
        return m.incident().version;
    }

    private long decline(String incidentId, String memberId) {
        Incident inc = store.get(incidentId);
        boolean canDecline = inc.status == Status.ESCALATING && inc.assignment(memberId)
                .map(a -> a.role == Role.NEARBY && a.state == AssignmentState.NOTIFIED).orElse(false);
        if (!canDecline) {
            throw ApiException.invalidState(memberId + " cannot decline now");
        }
        Map<String, Person> people = store.people();
        Optional<Assignment> next = nextAfter(inc, memberId);
        String nextTask = next.map(a -> tasks.schedule(incidentId, a.memberId, 1, inc.demo.timerSeconds)).orElse(null);
        IncidentStore.Mutation m = store.mutate(incidentId, (x, now) -> {
            requireStatus(x, Status.ESCALATING);
            Assignment a = x.assignment(memberId)
                    .filter(as -> as.role == Role.NEARBY && as.state == AssignmentState.NOTIFIED)
                    .orElseThrow(() -> ApiException.invalidState(memberId + " cannot decline now"));
            a.state = AssignmentState.DECLINED;
            a.respondedAt = now;
            x.log(now, memberId, "DECLINED", EscalationRules.name(people, memberId) + " cannot go");
            notifyNextOrGiveUp(x, now, nextTask, people);
            return true;
        });
        tasks.deleteQuietly(tasks.taskName(incidentId, memberId, 1));
        return m.incident().version;
    }

    private long arrived(String incidentId, String memberId) {
        Map<String, Person> people = store.people();
        return store.mutate(incidentId, (x, now) -> {
            requireStatus(x, Status.ESCALATING);
            if (!memberId.equals(x.ownerId)) {
                throw ApiException.invalidState("Only the member on the way can mark arrival");
            }
            Assignment a = x.assignment(memberId).orElseThrow();
            a.state = AssignmentState.ARRIVED;
            a.arrivedAt = now;
            x.status = Status.ON_SCENE;
            x.log(now, memberId, "ARRIVED", EscalationRules.name(people, memberId) + " arrived");
            return true;
        }).incident().version;
    }

    private long called115(String incidentId, String memberId) {
        Map<String, Person> people = store.people();
        return store.mutate(incidentId, (x, now) -> {
            x.assignment(memberId).filter(a -> a.state != AssignmentState.QUEUED)
                    .orElseThrow(() -> ApiException.invalidState(memberId + " has not been notified"));
            x.log(now, memberId, "CALLED_115", EscalationRules.name(people, memberId) + " called 115");
            return true;
        }).incident().version;
    }

    private long close(String incidentId, String memberId) {
        if (!"console".equals(memberId)) {
            throw ApiException.invalidState("Only the demo console can close an incident");
        }
        IncidentStore.Mutation m = store.mutate(incidentId, (x, now) -> {
            if (x.status == Status.CLOSED) {
                throw ApiException.invalidState("Incident is already closed");
            }
            x.status = Status.CLOSED;
            x.log(now, "SYSTEM", "CLOSED", "Closed from the demo console");
            return true;
        });
        tasks.deleteQuietly(m.incident().escalationTaskName);
        return m.incident().version;
    }

    private static boolean timedOut(Incident inc, String memberId) {
        return inc.status == Status.ESCALATING && inc.ownerId == null
                && inc.assignment(memberId).map(a -> a.state == AssignmentState.NOTIFIED).orElse(false);
    }

    private static Optional<Assignment> nextAfter(Incident inc, String memberId) {
        return inc.assignments.stream()
                .filter(a -> a.role == Role.NEARBY && a.state == AssignmentState.QUEUED && !a.memberId.equals(memberId))
                .findFirst();
    }

    private static void notifyNextOrGiveUp(Incident x, String now, String nextTask, Map<String, Person> people) {
        Optional<Assignment> next = EscalationRules.nextQueued(x);
        if (next.isPresent() && nextTask != null) {
            EscalationRules.notify(x, next.get(), now, nextTask, people);
        } else {
            EscalationRules.noNearby(x, now);
        }
    }

    private static void requireStatus(Incident x, Status status) {
        if (x.status != status) {
            throw ApiException.invalidState("Incident is " + x.status);
        }
    }
}
```

```java
@Service
public class Handoff {

    private final IncidentStore store;
    private final RespondAgentClient agent;
    private final RoutesClient routes;

    public Handoff(IncidentStore store, RespondAgentClient agent, RoutesClient routes) {
        this.store = store;
        this.agent = agent;
        this.routes = routes;
    }

    public void start(String incidentId) {
        Incident inc = store.get(incidentId);
        Person person = store.person(inc.personId);
        boolean stroke = inc.hasSlurredTurn();
        List<Hospital> candidates = store.hospitals().stream().filter(h -> !stroke || h.strokeReady).toList();
        if (candidates.isEmpty()) {
            return;
        }
        Map<String, Integer> eta = new HashMap<>();
        for (Hospital h : candidates) {
            routes.etaMinutes(person.location, h.location).ifPresent(m -> eta.put(h.id, m));
        }
        Hospital chosen = candidates.stream()
                .min(Comparator.comparingDouble(h -> eta.containsKey(h.id) ? eta.get(h.id) : 1000 + distance(person, h)))
                .orElseThrow();

        store.mutate(incidentId, (x, now) -> {
            if (x.handoff != null) {
                return false;
            }
            x.handoff = new HandoffInfo();
            x.handoff.hospitalId = chosen.id;
            x.handoff.hospitalName = chosen.name;
            x.handoff.etaMin = eta.get(chosen.id);
            x.handoff.status = "PENDING";
            x.handoff.sentAt = now;
            x.log(now, "SYSTEM", "HANDOFF_SENT", "Pre-arrival packet sent to " + chosen.name);
            return true;
        });

        HandoffResult result;
        try {
            result = agent.handoff(body(inc, person, stroke, chosen, eta.get(chosen.id)));
        } catch (AgentException e) {
            result = new HandoffResult("FAILED", null, true);
        }
        HandoffResult r = result;
        store.mutate(incidentId, (x, now) -> {
            x.handoff.status = "RECEIVED".equals(r.status()) ? "RECEIVED" : "FAILED";
            x.handoff.packet = r.packet();
            if ("RECEIVED".equals(x.handoff.status)) {
                x.log(now, "SYSTEM", "HANDOFF_RECEIVED", chosen.name + " received the packet");
            } else {
                x.log(now, "SYSTEM", "HANDOFF_FAILED", "Could not reach " + chosen.name);
            }
            return true;
        });
    }

    private Map<String, Object> body(Incident inc, Person person, boolean stroke, Hospital h, Integer etaMin) {
        Map<String, Object> hospital = new HashMap<>();
        hospital.put("id", h.id);
        hospital.put("name", h.name);
        if (etaMin != null) {
            hospital.put("etaMin", etaMin);
        }
        Map<String, Object> body = new HashMap<>();
        body.put("incidentId", inc.id);
        body.put("personId", inc.personId);
        body.put("level", inc.level.name());
        body.put("suspected", stroke ? "STROKE" : "UNKNOWN");
        body.put("lastKnownWellAt", inc.lastKnownWellAt);
        body.put("findings", inc.triage == null ? List.of() : inc.triage.reasons);
        body.put("hospital", hospital);
        // ponytail: first NEARBY member, not the owner; nobody has accepted yet when handoff runs
        Optional.ofNullable(person.circle).flatMap(c -> c.stream().filter(e -> e.role == Role.NEARBY).findFirst())
                .ifPresent(e -> body.put("onScene", Map.of("name", store.person(e.memberId).displayName, "relation", e.relation)));
        return body;
    }

    private static double distance(Person p, Hospital h) {
        double dLat = p.location.lat - h.location.lat;
        double dLng = p.location.lng - h.location.lng;
        return Math.sqrt(dLat * dLat + dLng * dLng);
    }
```

```java
package com.noonealone.coreapi.web;

import java.io.IOException;
import java.util.function.Predicate;

import org.springframework.web.filter.OncePerRequestFilter;

import jakarta.servlet.FilterChain;
import jakarta.servlet.ServletException;
import jakarta.servlet.http.HttpServletRequest;
import jakarta.servlet.http.HttpServletResponse;

public class AuthFilter extends OncePerRequestFilter {

    private final boolean enabled;
    private final Predicate<String> userToken;
    private final Predicate<String> serviceToken;

    public AuthFilter(boolean enabled, Predicate<String> userToken, Predicate<String> serviceToken) {
        this.enabled = enabled;
        this.userToken = userToken;
        this.serviceToken = serviceToken;
    }

    @Override
    protected boolean shouldNotFilter(HttpServletRequest request) {
        String path = request.getRequestURI();
        return !enabled || path.equals("/health") || path.equals("/api/health");
    }

    @Override
    protected void doFilterInternal(HttpServletRequest request, HttpServletResponse response, FilterChain chain)
            throws ServletException, IOException {
        String path = request.getRequestURI();
        String header = request.getHeader("Authorization");
        String token = header != null && header.startsWith("Bearer ") ? header.substring(7) : null;
        boolean ok;
        if (path.startsWith("/api/")) {
            ok = token != null && userToken.test(token);
        } else if (path.equals("/alerts") || path.startsWith("/tasks/")) {
            ok = token != null && serviceToken.test(token);
        } else {
            ok = true;
        }
        if (!ok) {
            response.setStatus(HttpServletResponse.SC_UNAUTHORIZED);
            response.setContentType("application/json");
            response.getWriter().write("{\"error\":{\"code\":\"UNAUTHENTICATED\",\"message\":\"Missing or invalid token\"}}");
            return;
        }
        chain.doFilter(request, response);
    }
}
```

```java
package com.noonealone.coreapi.config;

import java.io.IOException;
import java.util.function.Predicate;

import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import com.google.auth.oauth2.GoogleCredentials;
import com.google.auth.oauth2.TokenVerifier;
import com.google.firebase.FirebaseApp;
import com.google.firebase.FirebaseOptions;
import com.google.firebase.auth.FirebaseAuth;
import com.noonealone.coreapi.web.AuthFilter;

@Configuration
public class AuthConfig {

    @Bean
    AuthFilter authFilter(NoaProperties props) throws IOException {
        if (!props.auth().enabled()) {
            return new AuthFilter(false, t -> false, t -> false);
        }
        if (FirebaseApp.getApps().isEmpty()) {
            FirebaseApp.initializeApp(FirebaseOptions.builder()
                    .setCredentials(GoogleCredentials.getApplicationDefault())
                    .setProjectId(props.projectId())
                    .build());
        }
        TokenVerifier oidc = TokenVerifier.newBuilder().setAudience(props.auth().audience()).build();
        Predicate<String> user = token -> {
            try {
                FirebaseAuth.getInstance().verifyIdToken(token);
                return true;
            } catch (Exception e) {
                return false;
            }
        };
        Predicate<String> service = token -> {
            try {
                Object email = oidc.verify(token).getPayload().get("email");
                return props.auth().invokerEmail().equals(email);
            } catch (Exception e) {
                return false;
            }
        };
        return new AuthFilter(true, user, service);
    }
}
```
